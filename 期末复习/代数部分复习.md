## 第一题：环的类型判定

> 韩云光原话："给你一个集合两个运算，让你判断它属于什么环"

### 核心套路：逐条验证环的公理

1. 加法交换群：封闭 → 结合律 → 零元 → 逆元 → 交换律
2. 乘法封闭 + 结合律
3. 分配律（左 + 右）

**进一步判断**：
- 含幺环：乘法有单位元 1（且 1 ≠ 0）
- 交换环：乘法满足交换律
- 整环：含幺 + 交换 + 无零因子
- 除环：含幺 + 每个非零元有乘法逆元
- 域：交换除环 = 整环 + 每个非零元有逆元

### 练习 1 — $A=\{a+b\sqrt{2}\mid a,b\in\mathbb{Z}\}$，证环

任取 $x=a+b\sqrt{2}$，$y=c+d\sqrt{2}$。

加法封闭：$x+y=(a+c)+(b+d)\sqrt{2}\in A$ ✓
零元 $0=0+0\sqrt{2}$，逆元 $-x=(-a)+(-b)\sqrt{2}$

乘法封闭：$xy=(ac+2bd)+(ad+bc)\sqrt{2}\in A$ ✓

继承实数结合律、分配律。含幺 $1=1+0\sqrt{2}$，乘法交换 → **含幺交换环**。

### 练习 2 — $A=\{a+b\sqrt{3}\mid a,b\in\mathbb{Q}\}$，证域

在上面环的基础上，还需：每个非零元有乘法逆元。

$$x^{-1}=\frac{1}{a+b\sqrt{3}}=\frac{a-b\sqrt{3}}{a^2-3b^2}$$

分母 $a^2-3b^2\neq 0$（因为 $\sqrt{3}$ 无理，$a,b\in\mathbb{Q}$ 不全零）。结果系数仍在 $\mathbb{Q}$。

结论：含幺 + 交换 + 每非零元可逆 → **域**。

### 练习 3 — $\mathbb{Z}_6$ 的全部零因子

非零元素两两试乘，积 ≡ 0 (mod 6) 即为零因子：

- $2\otimes 3=6\equiv 0$ → 2 是零因子
- $3\otimes 2=6\equiv 0$ → 3 是零因子
- $4\otimes 3=12\equiv 0$ → 4 是零因子
- 1,5 不是零因子（与 6 互素）

答案：**2, 3, 4**。

### 练习 4 — 除环 ⇒ 无零因子

设 $ab=0$ 且 $a\neq 0$。除环中非零元有逆元，左乘 $a^{-1}$：

$$a^{-1}(ab)=a^{-1}\cdot0 \implies b=0$$

同理若 $b\neq 0$ 则右乘 $b^{-1}$ 得 $a=0$。所以 $a,b$ 至少一个为零。

### 练习 5 — 加法是循环群 ⇒ 交换环

加法循环 ⇒ 任意 $x=mu$，$y=nu$（$m,n\in\mathbb{Z}$）。

$$xy=(mu)(nu)=(mn)(u\cdot u)=(nm)(u\cdot u)=yx$$

## 第二题：变换群/置换群的运算

> 韩云光原话："变换群，让你求这个元素的阶，书上习题也有"

### 核心技能

| 操作 | 方法 |
|------|------|
| 化简 | 写成不相交轮换之积 |
| 求阶 | 各轮换长度的最小公倍数 LCM |
| 求逆 | 每个轮换倒过来写 |
| 复合 | 先右后左，逐元素追踪 |
| 解方程 | $\alpha x=\beta \implies x=\alpha^{-1}\beta$（左乘逆元） |
| 求子群 | 循环群各阶子群 = 阶的每个正因子对应一个 |

### 练习 1 — $S_4$ 中置换运算

$$\sigma=(12)(34),\quad\tau=(1324)$$

化成轮换后：
- $\sigma\tau=(1423)$，$\tau\sigma=(1423)$（巧了，$\sigma=\tau^2$）
- $\sigma^{-1}=(12)(34)=\sigma$（对换的逆是自身）
- $\tau^{-1}=(1423)$（四轮换倒写）
- $|\sigma|=\operatorname{lcm}(2,2)=2$，$|\tau|=4$

### 练习 2 — $S_6$ 中解方程

$$\alpha=(1\ 5\ 2\ 3\ 6\ 4),\quad\beta=(1\ 4\ 2\ 3\ 5\ 6),\quad \alpha x=\beta$$

先求 $\alpha^{-1}$（两行互换再排序），然后 $x=\alpha^{-1}\beta$，逐点算：

$$x=(1\ 6\ 5\ 3\ 2\ 4)$$

$|x|=6$，$\langle x\rangle$ 子群对应 6 的因子 1,2,3,6：
- 1 阶：$\{e\}$
- 2 阶：$\langle x^3\rangle=\{e,(13)(26)(45)\}$
- 3 阶：$\langle x^2\rangle=\{e,(152)(346),(125)(364)\}$
- 6 阶：全群

### 练习 3 — $S_8$ 中阶为 2 的元素

阶 2 ↔ 只含不相交对换：

- 1 个对换：$(a\ b)$，共 28 个
- 2 个对换：$(a\ b)(c\ d)$，共 210 个
- 3 个对换：$(a\ b)(c\ d)(e\ f)$，共 420 个
- 4 个对换：$(a\ b)(c\ d)(e\ f)(g\ h)$，共 105 个

### 练习 4 — 6 阶循环群生成元与子群

$G=\langle a\rangle$，$|G|=6$。

生成元：$\gcd(k,6)=1$ → $a, a^5$

子群（6 的正因子 1,2,3,6）：
- $\{e\}$、$\langle a^3\rangle$、$\langle a^2\rangle$、$G$

## 第三题：两个代数系统之间的同态关系

> 韩云光原话："给两个系统，找出它之间所有的同态关系"

### 核心思路

同态条件：$f(x\circ y)=f(x)*f(y)$，且 $f(e_G)=e_H$。

对于有限群，关键是利用"**阶对像的约束**"：
- 若 $a^n=e$，则 $f(a)^n=e$，即 $|f(a)|\mid|a|$
- 由此推出 $f(a)$ 的阶必须同时整除 $|a|$ 和目标群中对应元素的阶

### 练习 1 — Klein 群 → $\mathbb{Z}_4$ 所有同态

Klein 群 $K_4=\{e,a,b,c\}$，$a^2=b^2=c^2=e$，$c=ab$。
$\mathbb{Z}_4=\{0,1,2,3\}$，模 4 加法。

由 $2f(a)\equiv0\pmod4$，$2f(b)\equiv0\pmod4$ → $f(a),f(b)\in\{0,2\}$。
再由 $f(c)=f(a)+f(b)\pmod4$，共得 4 个同态：

| | f(e) | f(a) | f(b) | f(c) |
|---|------|------|------|------|
| $f_0$ | 0 | 0 | 0 | 0 |
| $f_1$ | 0 | 2 | 0 | 2 |
| $f_2$ | 0 | 0 | 2 | 2 |
| $f_3$ | 0 | 2 | 2 | 0 |

### 练习 2 — 判同态：$f:\mathbb{Z}\to\mathbb{Z}_7,\; f(x)=x\bmod7$

验证 $f(x+y)=f(x)\oplus f(y)$：
- $f(x+y)=(x+y)\bmod7$
- $f(x)\oplus f(y)=(x\bmod7)+(y\bmod7)\bmod7$
两者相等 → **是同态**。

### 练习 3 — 同态保持阶的整除

$f:G\to H$ 同态，$x\in G$ 有限阶，证 $|f(x)|\mid|x|$。

设 $|x|=n$，则 $x^n=e_G$。两边取 $f$：
$$f(x)^n=f(x^n)=f(e_G)=e_H$$

所以 $f(x)^n=e_H$。元素的阶是使幂等于单位元的**最小**正整数，因此 $|f(x)|\mid n$。

## 常见易错点

1. **域 ≠ 环**：忘记证乘法逆元（分母有理化）
2. **零因子**：$a\neq0,b\neq0$ 但 $ab=0$；注意零元本身不算零因子
3. **置换复合顺序**：先右后左，$\sigma\tau(x)=\sigma(\tau(x))$
4. **轮换要不相交**：有相交元素的轮换不能直接交换
5. **同态映射**：不要漏掉零同态；先分析阶约束再枚举
6. **循环群生成元**：$a^k$ 生成元 ↔ $\gcd(k,n)=1$，不是随便取
