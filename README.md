# Mathematical Foundations of Information Security

《信息安全数学基础》课程笔记与复习资料。

## 内容结构

```
├── notes/        # 课堂笔记（47 篇，按日期+节次编排）
├── problems/     # 习题 · 模拟卷 · 专项练习
├── solutions/    # 习题解答 · 知识点总结
└── 期末复习/     # 考前复习提纲（代数 + 数论）
```

## 课程概要

- **代数部分**（徐敏）：群、环、域，同态与同构，置换群，理想与商环
- **数论部分**（韩云光）：整除与同余，欧拉/费马定理，一次与高次同余式，平方剩余与二次互反律，Legendre/Jacobi 符号
- **桥梁**：RSA 公钥密码、模 p 乘法群、克罗内克符号

## 使用方式

- 考前复习从 `期末复习/` 入手，先过知识框架
- 刷题做 `problems/` 下的四套模拟卷（A/B/C + 补漏专项）
- 遇到卡点查 `solutions/` 对应解答
- 深入理解看 `notes/` 按日期索引的课堂记录

笔记由课堂录播 ASR 字幕整理而来，标注了时间轴、关键概念和回看建议。少数几节因 API 返回空白无法生成字幕，标题已注明。
