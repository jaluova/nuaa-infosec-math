# 第1章 整数的可除性 习题

1. 判断下面两数是否满足 $x \mid y$。
    (1) $x = 2467,\ y = 545\,207$；
    (2) $x = 142,\ y = 35\,768$。

2. 证明：
    (1) 若 $3 \mid a,\ 4 \mid a,\ 5 \mid a$，则 $60 \mid a$；
    (2) 若 $x \mid a,\ y \mid a$，则 $[x,\ y] \mid a$。

3. 求最大公因数，并将其表示为两数的整系数线性组合。
    (1) $169,\ 121$；
    (2) $1515,\ 600$；
    (3) $1859,\ 1573$；
    (4) $24\,871,\ 3468$。

4. 求最小公倍数。
    (1) $1250,\ 35$；
    (2) $136,\ 221,\ 391$。

5. 已知正整数 $a$ 和 $b$，满足 $ab = 40$，且 $[a,\ b] = 20$，求 $(a,\ b)$。

13. 构造不超过 $100$ 的素数表。

14. 写出下列整数的唯一分解式：
    (1) $346\,502$；
    (2) $598\,673$；
    (3) $356\,940$。

16. 求下列不定方程的一切整数解：
    (1) $6x + 93y = 75$；
    (2) $9x + 21y = 144$；
    (3) $345x + 1225y = 75$；
    (4) $987x + 2668y = 610$。

17. 把 $100$ 个苹果分成两堆，使得一堆的个数被 $7$ 整除，另一堆的个数被 $11$ 整除。

18. 两个容器，一个容量为 $27\,\text{L}$，另一个容量为 $15\,\text{L}$，如何利用它们从一桶油中倒出 $6\,\text{L}$ 油来？（设桶的容量为任意大）
