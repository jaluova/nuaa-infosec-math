## 关键概念
- **二元一次不定方程**：形如 $ax+by=c$，其中 $a,b,c$ 为整数，$x,y$ 为未知整数，未知数个数（2个）多于方程个数（1个），称为不定方程
- **充要条件**：$ax+by=c$ 有整数解 $\iff$ $(a,b) \mid c$
- **特解**：方程的一组具体整数解 $(x_0, y_0)$
- **通解**：当 $a_1 = a/(a,b),\; b_1 = b/(a,b)$ 且 $(x_0,y_0)$ 为特解时，全部解为 $x = x_0 - b_1 t,\; y = y_0 + a_1 t$，其中 $t \in \mathbb{Z}$
- **丢番图方程**：求整数解的不定方程，公元三世纪丢番图已有研究

## 要点详述

### 主题一：有解判定定理（充要条件）

**定理**：二元一次不定方程 $ax+by=c$ 有整数解的充分必要条件是 $(a,b) \mid c$，即 $a$ 与 $b$ 的最大公约数整除 $c$。

**必要性证明**（较简单）：
设 $(a,b)=d$。若方程有整数解 $(x,y)$，则 $c = ax + by$。由于 $d \mid a$ 且 $d \mid b$，所以 $d \mid (ax+by) = c$。

**充分性证明**（核心在于利用 $d=as+bt$ 的形式）：
由第一章的结论，存在整数 $s,t$ 使得 $as + bt = d$。设 $c = d \cdot c_1$（因为 $d \mid c$），则方程两边同乘 $c_1$：
$$a(s c_1) + b(t c_1) = d \cdot c_1 = c$$
因此 $(x_0, y_0) = (s c_1, t c_1)$ 就是一组特解。

老师强调：这个证明说明**一切的关键最终都回到辗转相除法**——$s$ 和 $t$ 正是通过辗转相除法的反向代入得到的。

### 主题二：从百鸡问题到一般形式

古代"百鸡问题"（百钱买百鸡）：公鸡一只五钱，母鸡一只三钱，小鸡三只一钱，一百钱买一百只鸡，问各几只。

翻译为数学语言：设公鸡 $x$ 只、母鸡 $y$ 只、小鸡 $z$ 只。
$$\begin{cases} x + y + z = 100 \\[4pt] 5x + 3y + \frac{1}{3}z = 100 \end{cases}$$

消去 $z$ 得：$7x + 4y = 100$，这就是一个二元一次不定方程的实例。

对 $7x+4y=100$，由于 $(7,4)=1 \mid 100$，所以有整数解。先求 $7s+4t=1$ 的特解（显然 $s=-1, t=2$），则原方程特解为 $(-100, 200)$。通解为：
$$x = -100 - 4t,\quad y = 200 + 7t,\quad t \in \mathbb{Z}$$

### 主题三：通解公式的推导

当 $d=(a,b)$，记 $a = a_1 d,\; b = b_1 d$（此时 $a_1, b_1$ 互质），设 $(x_0, y_0)$ 是方程的一组特解。

**正向验证**（形式为 $x_0 - b_1 t,\; y_0 + a_1 t$ 的数一定是解）：
$$a(x_0 - b_1 t) + b(y_0 + a_1 t) = ax_0 + by_0 - a b_1 t + b a_1 t = c$$
因为 $a b_1 = a_1 d \cdot b_1 = a_1 b_1 d$，$b a_1 = b_1 d \cdot a_1 = a_1 b_1 d$，这两项恰好抵消。

**反向证明**（方程的任意解必可写成此形式）：
设 $(x', y')$ 是任意解，则 $ax' + by' = c$。与特解 $ax_0 + by_0 = c$ 相减：
$$a(x' - x_0) + b(y' - y_0) = 0 \;\Rightarrow\; a_1(x' - x_0) = -b_1(y' - y_0)$$
由于 $a_1$ 整除右边，而 $(a_1, b_1) = 1$，利用互质性质可得 $a_1 \mid (y_0 - y')$，于是存在整数 $t$ 使得 $y' = y_0 + a_1 t$。代回原式可得 $x' = x_0 - b_1 t$。

### 主题四：大数分解与密码学

老师在介绍算术基本定理时特别指出：理论上任何大于1的整数都可以唯一分解为标准分解式，但**实际中对大整数做质因数分解极其困难**。这种大数分解的困难性正是现代密码学（如RSA）的理论基础——RSA的安全性正是建立在"两个大质数的乘积容易计算，但从乘积反推质因子极其困难"这一事实上。
