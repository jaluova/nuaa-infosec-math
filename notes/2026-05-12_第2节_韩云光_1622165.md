# 2.7 Hensel提升法 — 从模 $p$ 到模 $p^k$ 的阶梯提升

## 本节主线

本节课是第2章最难的部分。核心问题是：已知 $f(x)\equiv 0 \pmod{p}$ 的一个解 $x_1$，如何将其"提升"为 $f(x)\equiv 0 \pmod{p^\alpha}$ 的解。基本思想是逐级上台阶：$p \to p^2 \to p^3 \to \cdots \to p^\alpha$，每一步将解表示为 $x_k = x_{k-1} + p^{k-1} \cdot t_{k-1}$，通过泰勒展开和同余化简，将问题转化为关于 $t_{k-1}$ 的一次同余式。

## 关键概念

- **Hensel提升（上台阶）**：从模 $p$ 的解出发，逐级构造模 $p^2,p^3,\ldots,p^\alpha$ 的唯一解
- **唯一提升的条件**：$f'(x_1)\not\equiv 0 \pmod{p}$（导数与 $p$ 互质）
- **解的形式**：$x_k = x_{k-1} + p^{k-1} \cdot t_{k-1}$，其中 $t_{k-1}$ 由一次同余式确定
- **泰勒展开截断**：因 $p^k$ 整除 $p^2$ 及以上幂次（当 $k\ge 2$），展开式第三项开始均可消去
- **三种提升情况预告**：
  - 情况一：$f'(x_1)\not\equiv 0\pmod{p}$ → 唯一提升
  - 情况二：$f'(x_1)\equiv 0\pmod{p}$ 且右边被 $p$ 整除 → 分叉（$p$ 个解都能提升）
  - 情况三：$f'(x_1)\equiv 0\pmod{p}$ 且右边不被 $p$ 整除 → 无解（消亡）

## 要点详述

### 1. 提升的核心推导（$p\to p^2$）

设 $x_1$ 为模 $p$ 解，令 $x = x_1 + pt_1$。代入：

$$f(x_1+pt_1) = f(x_1) + f'(x_1)pt_1 + \frac{f''(x_1)}{2!}p^2t_1^2 + \cdots$$

模 $p^2$ 下，第三项起均 $\equiv 0$。要求 $f(x_1+pt_1)\equiv 0\pmod{p^2}$：

$$f(x_1) + f'(x_1)pt_1 \equiv 0 \pmod{p^2}$$

因 $f(x_1)=p\cdot k$（是 $p$ 的倍数），两边同除 $p$：

$$\frac{f(x_1)}{p} + f'(x_1)t_1 \equiv 0 \pmod{p}$$

这是一次同余式 $at_1 \equiv b \pmod{p}$，其中 $a=f'(x_1)$，$b=-\frac{f(x_1)}{p}$。当 $\gcd(f'(x_1),p)=1$ 时，有唯一解。

### 2. 迭代的一般形式

在从 $p^{\alpha-1}$ 提升到 $p^\alpha$ 时，得到：

$$\frac{f(x_{\alpha-1})}{p^{\alpha-1}} + f'(x_{\alpha-1}) \cdot t_{\alpha-1} \equiv 0 \pmod{p}$$

由于 $f'(x_{\alpha-1}) \equiv f'(x_1) \pmod{p}$，每一步的条件都由第一步的导数决定。
