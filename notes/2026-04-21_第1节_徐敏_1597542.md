## 关键概念
- **贝祖定理（Bezout 恒等式）**：∀a,b 不全为零，∃s,t∈Z: as+bt=(a,b)；s,t 不唯一
- **辗转相除逆过程**：从最后一步非零余数出发，逐层向上回代，将 r_n 表示为 a,b 的线性组合
- **最大公因数的乘法性质**：(ma, mb) = |m|·(a,b)
- **最大公因数的除法性质**：若 d|a, d|b，则 (a/d, b/d) = (a,b)/|d|
- **定理 1.5**：若 (a,c)=1，则 (ab, c) = (b, c)
- **互素充要条件**：(a,b)=1 ⟺ ∃s,t∈Z, as+bt=1
- **最小公倍数（LCM）**：所有正公倍数中最小的那个；符号 [a₁,...,aₖ]
- **LCM 公式**：[a,b] = ab / (a,b)
- **公倍数的结构**：a,b 的所有公倍数恰好是 [a,b] 的所有倍数

### 主题二：贝祖定理——辗转相除的逆过程

**核心思想**：辗转相除的"顺过程"从上往下做（数字越来越小），"逆过程"则从下往上回代，将 GCD 表示为原始两数的线性组合。

**定理 1.3（贝祖定理 / Bezout's Identity）**：设 a, b 为不全为零的整数，则存在整数 s, t 使得：
$$as + bt = (a, b)$$

s, t 称为贝祖系数，且不唯一。

**构造性证明**：

辗转相除的最后两步为：
$$r_{n-2} = r_{n-1} q_n + r_n$$
$$r_{n-1} = r_n q_{n+1} + 0$$

从倒数第二步出发：
$$r_n = r_{n-2} - r_{n-1} \cdot q_n$$

此时 r_n 已表示为 r_{n-2} 和 r_{n-1} 的线性组合。再看上一步：
$$r_{n-3} = r_{n-2} q_{n-1} + r_{n-1}$$

将 r_{n-1} 解出：$r_{n-1} = r_{n-3} - r_{n-2} q_{n-1}$，代入前面的表达式消去 r_{n-1}，r_n 即表示为 r_{n-3} 和 r_{n-2} 的组合。

如此反复回代，每步将下标最低的 r_i 用更高层的 r_{i−1} 和 r_{i−2} 替换。最终 a 和 b 就是最高层的 r 变量，r_n 因此可表示为 a 和 b 的线性组合：
$$r_n = (a,b) = as + bt$$

**完整例题：288 和 158**

顺过程（辗转相除）：
```
288 = 158 × 1 + 130
158 = 130 × 1 + 28
130 = 28 × 4 + 18
28 = 18 × 1 + 10
18 = 10 × 1 + 8
10 = 8 × 1 + 2
8 = 2 × 4 + 0
```
故 (288, 158) = 2。

需要说明的是，徐老师在第一行做了简化处理：原来标准的带余除法应得 288 = 158×1 + 130，但为了方便后续计算，有时会取较大的商使余数绝对值更小（如取 q=2 使 r=−28），这样后续步骤中的数字更小。实际做法看个人习惯，不影响最终 GCD 和回代结果。

逆过程（从下往上回代）：
```
2 = 10 − 8×1
  = 10 − (18−10×1)×1 = 2×10 − 18
  = 2×(28−18×1) − 18 = 2×28 − 3×18
  = 2×28 − 3×(130−28×4) = 14×28 − 3×130
  = 14×(158−130×1) − 3×130 = 14×158 − 17×130
  = 14×158 − 17×(288−158×1) = 31×158 − 17×288
```

故 s = −17, t = 31，即 −17 × 288 + 31 × 158 = 2，验证：−4896 + 4898 = 2。✓

**与不定方程的联系**：方程 288x + 158y = 2 在实数域上有无穷多解（一条直线上的所有点），但在整数域上只有特定解。求出的 (−17, 31) 是一组特解。此类"二元一次不定方程"的完整理论将在 1.5 节学习。

**s, t 不唯一**：按照不同的回代路径或不同的简化方式（传转相除中余数符号的选择），会得到不同的 s, t 对，但它们能生成相同的解集合。

### 主题三：最大公因数的乘除运算性质

**定理 1.4（乘法性质）**：设 m 为正整数，则：
$$(ma, mb) = m \cdot (a, b)$$

证明思路（徐老师指出用辗转相除法）：对 ma 和 mb 做辗转相除，每一步相当于对 a, b 辗转相除的对应步骤两边同时乘以 m。故最后非零余数也乘以 m。

直观理解：如果要研究"放大 m 倍以后"的 GCD，只需先求原数的 GCD 再放大 m 倍。这是 GCD 运算的齐次性。

**除法性质（定理 1.4 推论）**：若 d 是 a, b 的公因数（即 d|a 且 d|b），则：
$$\left(\frac{a}{d}, \frac{b}{d}\right) = \frac{(a, b)}{|d|}$$

特别关键的特殊情形——取 d = (a, b)：
$$\left(\frac{a}{(a,b)}, \frac{b}{(a,b)}\right) = 1$$

即：两个数除以它们的最大公因数后，一定互素。这意味着最大公因数恰好"剥离"了两个数之间所有的公共因子，剩下的部分没有任何交集。

**应用**：记 a₁ = a/(a,b), b₁ = b/(a,b)。则 a = a₁·(a,b), b = b₁·(a,b)，且 (a₁, b₁) = 1。这种"去公因子的标准化"写法在后续证明中将反复出现。

### 主题四：互素相关的整除定理（定理 1.5）

**定理 1.5**：若 (a, c) = 1（a 与 c 互素），则：
$$(ab, c) = (b, c)$$

直观理解：c 与 a 互素意味着 a 不"贡献"任何与 c 公共的素因子。因此求 ab 与 c 的 GCD 时，a 是"多余"的——可以安全删除，结果等价于 b 与 c 的 GCD。

**严格证明**（集合视角 + 贝祖技巧）：

设集合 A = {d | d|ab 且 d|c}（ab 与 c 的公因数集合），
集合 B = {d | d|b 且 d|c}（b 与 c 的公因数集合）。

- **B ⊆ A**（←方向，简单）：若 d|b，显然 d|ab，所以 B 中元素都满足 A 的条件。
- **A ⊆ B**（→方向，需要技巧）：若 d|ab 且 d|c。由 (a,c)=1 及贝祖定理，∃s,t: as + ct = 1。等式两边乘以 b：
  $$abs + cbt = b$$
  由于 d|ab 且 d|c，d 整除等式左边的每一项 ⇒ d|b。结合 d|c，得 d ∈ B。

因此 A = B，max A = max B ⇒ (ab,c) = (b,c)。

**技巧要点**：A ⊆ B 是关键方向。核心在于将"d 整除 ab"通过贝祖恒等式 as+ct=1 转化为"d 整除 b"。等式两边乘 b 这一构造手法是数论中常用的"桥梁"技巧。

**推论 1**：若 (a,c)=1 且 c | ab，则 c | b。

直观：c 要整除 ab，但它与 a 没有公因子，所以 c 的因子只能从 b 中获取，即 c 必须整除 b。

证明：由 c|ab 及定理 1.5，(ab,c) = |c| = (b,c)，故 |c| = (b,c) ⇒ c|b。

**推论 2（推广）**：若两组数 {a₁,...,aₘ} 和 {b₁,...,bₙ} 中任何 a_i 与任何 b_j 都互素，则两组数的乘积也互素，即：
$$(a_1 a_2 \cdots a_m,\; b_1 b_2 \cdots b_n) = 1$$

证明思路：反复应用定理 1.5，每次消去一个 a_i，最终只剩 1。

### 主题五：互素的充要条件（定理 1.6）

**定理 1.6**：a 与 b 互素的充要条件是存在整数 s, t 使得 as + bt = 1。

**必要性（⇒）**：即贝祖定理在 (a,b)=1 时的特殊情形。显然成立。

**充分性（⇐）**：若 ∃s,t: as + bt = 1。设 d = (a,b)，则 d|a 且 d|b ⇒ d|(as + bt) = 1 ⇒ d = 1。故 (a,b)=1，a 与 b 互素。

这个定理将"互素"这一关于因数的概念转化为"存在性"的等式——存在 s,t 使 as+bt=1。前者是"否定性"的定义（没有大于 1 的公因数），后者是"存在性"的刻画（存在某个线性组合得到 1）。两者完全等价，在证明中可以灵活切换。

### 主题六：最小公倍数——定义与核心定理

**定义 1.4**：非零整数 a₁, ..., aₖ 的所有正公倍数中最小的那个称为最小公倍数，记作 [a₁, a₂, ..., aₖ]。符号使用中括号（最大公因数用小括号）。

**为何关注"最小"**：在公因数中我们关注最大公因数（因为 1 总是公因数，最小的没价值）；在公倍数中我们关注最小公倍数（因为所有数的乘积总是一个公倍数，最大的可无限增大，没价值）。关注"极端值中有意义的那个"。

**基本性质**：
- [a₁,...,aₖ] = [|a₁|,...,|aₖ|]（取绝对值不改变 LCM）
- 对任意正整数 a,b，[a,b] 必然存在（因为 ab 就是一个公倍数，LCM 不超过它）

**核心定理**：
1. a 和 b 的所有公倍数恰好是 [a,b] 的所有倍数
2. $$[a, b] = \frac{ab}{(a, b)}$$

**严格证明**：

令 d = (a,b)。记 a = a₁d, b = b₁d，其中 (a₁, b₁) = 1（由 GCD 除法性质的推论）。

设 m 是 a, b 的任意公倍数：∃k,k': m = ak = bk'。代入：
$$a_1 d k = b_1 d k' \;\Rightarrow\; a_1 k = b_1 k'$$

由 a₁ | b₁k' 且 (a₁,b₁)=1，根据定理 1.5 推论 1，推得 a₁ | k'。令 k' = a₁ t（t 为整数），则：
$$m = b k' = b \cdot a_1 t = b \cdot \frac{a}{d} \cdot t = \frac{ab}{d} \cdot t$$

这说明任意公倍数 m 都能写成 (ab/d)·t 的形式，即 m 是 ab/d 的倍数。

反之，ab/d = a·(b/d) = b·(a/d)，显然同时是 a 的倍数和 b 的倍数（这里要求 d|a 和 d|b，确实 d 是公因数），所以 ab/d 本身是一个公倍数。

综合两方面：(1) 所有公倍数都是 ab/d 的倍数；(2) ab/d 本身是公倍数。因此 ab/d 就是最小公倍数：[a,b] = ab/(a,b)。

**推论**：a,b 的所有公倍数 = {k·[a,b] | k = 1,2,3,...}。

**练习 1**：求 [54, 45]。
54 = 6×9, 45 = 5×9，所以 (54,45)=9。由公式 [54,45] = 54×45/9 = 270。

**练习 2**：已知某正整数 x 满足 (x,24)=4, [x,24]=168，求 x。
由恒等式 a·b = (a,b)·[a,b]（直接从公式变形得到）：
x × 24 = 4 × 168 ⇒ x = 672/24 = 28。
验证：(28,24)=4 ✓, [28,24]=168 ✓。

### 主题七：多个数的最小公倍数

与 GCD 完全同样的策略：
$$[a_1, a_2, \ldots, a_k] = [[a_1, a_2], a_3, \ldots, a_k]$$

每次用公式求两个数的 LCM，结果再与下一个数合并。虽然多次计算比单次 GCD 稍繁琐，但原则上没有新困难。
