## 关键概念
- **带余除法唯一性**：满足 0 ≤ r < b 的商 q 和余数 r 由 a 和 b 唯一确定
- **整系数多项式带余除法**：f = g·q + r，r 的次数 < g 的次数（或 r=0），q 和 r 唯一
- **最大公因数（GCD）**：记 (a₁,...,aₙ)，是所有公因数中最大的；符号为小括号
- **互素（互质）**：(a₁,...,aₙ) = 1，称这 n 个数互素（整体互素）
- **两两互素**：任意两个都互素；强于整体互素
- **核心引理（欧几里得引理）**：a = bq + c ⇒ (a,b) = (b,c)
- **辗转相除法（欧几里得算法）**：反复做带余除法求 GCD 的算法，最后一个非零余数即为 GCD
- **公因数集合定理**：{a,b 的所有公因数} = {(a,b) 的所有正因数}

## 要点详述

### 主题一：带余除法唯一性的严格证明

承接上节的存在性证明（已通过数轴分割证得 ∃q,r 满足条件），现在证明唯一性。

**定理内容回顾**：∀a∈Z, b∈Z⁺, ∃! (q,r): a = bq + r, 0 ≤ r < b。

**唯一性证明**（反证法+不等式）：
假设有两组表示 a = bq + r = bq₁ + r₁，且均满足 0 ≤ r, r₁ < b。两式相减：
$$b(q - q_1) = r_1 - r$$

考虑绝对值：
$$|b| \cdot |q - q_1| = |r_1 - r|$$

由于 0 ≤ r, r₁ < b，可知 |r₁ − r| < b（两数都在 [0,b) 内，最大差值不超过 b−1）。

现在看左边：若 q ≠ q₁，则 |q − q₁| ≥ 1，左边 ≥ |b| = b。但右边 < b，矛盾！故 q = q₁，进而 r = r₁。唯一性证毕。

**韩老师点评**：看似一个"废话"般的命题（谁都知道除法只能得一个商和余数），但数学上需要严谨证明。带余除法虽简单，但它是整个初等数论的基石——后面辗转相除法、同余理论、连分数都建立在此之上。

**负数被除数例题**：a = −81, b = 15。

尝试 q = −6：15 × (−6) = −90，r = −81 − (−90) = 9。检查：0 ≤ 9 < 15，满足条件。

若 q = −7：15 × (−7) = −105，r = −81 − (−105) = 24（≥15，不满足 r<b）。

若 q = −5：15 × (−5) = −75，r = −81 − (−75) = −6（<0，不满足 r≥0）。

韩老师特别提醒：当 a 为负数时，商 q 应向负方向取整使余数落在 [0,b) 内，这与计算机中取模运算的行为一致（被除数为负时需小心）。

### 主题二：整系数多项式上的带余除法

**推广动机**：数学研究中常见的范式——从整数推广到多项式，从多项式推广到更抽象的结构。每一步推广保留核心性质，调整约束条件。

**多项式带余除法定义**：设 f(x) = aₙxⁿ + ... + a₀（aₙ ≠ 0, 整系数），g(x) = bₘxᵐ + ... + b₀（bₘ 为任意非零整数），则存在唯一的整系数多项式 q(x) 和 r(x) 使得：
$$f(x) = g(x) \cdot q(x) + r(x)$$
其中 deg(r) < deg(g) 或 r(x) ≡ 0。

**与整数情形的对应**：
| 整数情形 | 多项式情形 |
|---------|-----------|
| 除数 b > 0 | 除式 g(x) 非零 |
| 余数 0 ≤ r < b | 余式 deg(r) < deg(g) |
| 对 q 无额外约束 | 对 q 无额外约束 |

注意：多项式情形中 g(x) 的首项系数不要求为 1，只要求非零；这与整数情形中 b 必须是正整数有所不同。

**存在性证明（数学归纳法）**：
1. **n < m**（被除式次数 < 除式次数）：令 q(x)=0, r(x)=f(x)，自然满足
2. **n ≥ m**：引入对 n 的数学归纳法
   - **奠基 n = m**：令 q(x) = aₙ/bₘ（常数多项式），则 f − g·q 的最高次项被消去，余式次数 < m
   - **归纳假设**：设对次数 ≤ n−1 的被除式，定理成立
   - **归纳步骤（n > m）**：构造 q₁(x) = (aₙ/bₘ)·x^{n−m}，则 f − g·q₁ 的最高次项被消去，次数 < n。由归纳假设，存在 q₂, r 使 f − g·q₁ = g·q₂ + r，即 f = g·(q₁+q₂) + r，deg(r) < m

唯一性证明与整数情形完全类比（假设两套系数，推导导出差值为零）。

**课堂练习**：f(x) = x³ + 2x² − 5，g(x) = x² − 3x + 1。商为 x + 5，余式为 14x − 10（需核对具体数值，教材有标准答案）。

### 主题三：最大公因数——定义、互素与两两互素

**定义 1.3**：设 a₁, a₂, ..., aₙ 是不全为零的整数。若整数 d 同时整除其中每一个数，则 d 称为它们的公因数（公约数）。公因数中最大者称为最大公因数，记作 (a₁, a₂, ..., aₙ)。

**互素（互质）**：若 (a₁, ..., aₙ) = 1，称这 n 个数互素。

**两两互素 vs 整体互素**（重要区分）：
- 集合 {3, 5, 7, 13}：每两个数的 GCD 均为 1，即两两互素；整体 GCD 自然也是 1
- 集合 {4, 3, 8, 2}：(4,3,8,2) = 1（整体互素）；但 (4,8)=4≠1，所以并非两两互素

两两互素 ⇒ 整体互素；反之不成立。两两互素是更强的条件。

**基本性质**：
1. (a₁, ..., aₙ) = (|a₁|, ..., |aₙ|)：取绝对值不改变 GCD（因为因数是否带负号不影响整除关系）
2. 因此讨论 GCD 时只需考虑非负整数，负数可先取绝对值
3. (0, b) = |b|（b > 0 时即为 b 本身）：因为 0 能被任何整数整除（0 = d × 0），所以 0 和 b 的公因数就是 b 的所有因数，最大者为 b

### 主题四：核心引理——欧几里得引理

**引理**：若 a = bq + c（q 为整数，c 的符号任意），则 (a, b) = (b, c)。

**证明（集合视角）**：

记集合 A = {d | d|a 且 d|b}（a,b 的公因数集合），B = {d | d|b 且 d|c}（b,c 的公因数集合）。

- **A ⊆ B**：若 d ∈ A，则 d|a, d|b。由整除的线性组合性质（性质 4），d | (a − bq) = c。又 d|b，故 d ∈ B。
- **B ⊆ A**：若 d ∈ B，则 d|b, d|c。由 a = bq + c 及性质 3（和差），d | (bq + c) = a。又 d|b，故 d ∈ A。
- 因此 A = B，两集合的最大元素自然也相等：max A = max B ⇒ (a,b) = (b,c)。

韩老师特别偏好这种集合相等的方法，认为比纯代数推导更直观：两个集合一模一样，其中的最大元素自然相同。

**引理的实际威力**：每做一次带余除法，就把 GCD 问题中的数变小，直到最终出现 0。

示例链条（求 (18, 5)）：
- 18 = 5×3 + 3 ⇒ (18,5) = (5,3)
- 5 = 3×1 + 2 ⇒ (5,3) = (3,2)
- 3 = 2×1 + 1 ⇒ (3,2) = (2,1)
- 2 = 1×2 + 0 ⇒ (2,1) = (1,0) = 1
- 故 (18,5) = 1，两数互素

每一步都把一个较大的数替换为更小的余数，直到余数为 0 时终止。

### 主题五：辗转相除法（欧几里得算法）的完整流程

**算法表述**：对任意整数 a, b（不全为零），反复做带余除法：
$$\begin{aligned}
a &= b q_1 + r_1 & (0 \leq r_1 < b) \\
b &= r_1 q_2 + r_2 & (0 \leq r_2 < r_1) \\
r_1 &= r_2 q_3 + r_3 & (0 \leq r_3 < r_2) \\
&\;\vdots \\
r_{n-2} &= r_{n-1} q_n + r_n & (0 \leq r_n < r_{n-1}) \\
r_{n-1} &= r_n q_{n+1} + 0
\end{aligned}$$

关键观察：余数序列 r₁ > r₂ > r₃ > ... > r_n > 0 是严格递减的正整数序列，因此经过有限步后必然出现 r_{n+1}=0（算法终止）。

**结论**：(a,b) = r_n，即最后一个非零余数。

**证明**（从前向后推）：反复应用核心引理
$$(a,b) = (b, r_1) = (r_1, r_2) = \cdots = (r_{n-1}, r_n) = (r_n, 0) = r_n$$

每一对等号对应于辗转相除的一步，最后一步利用 (r_n, 0) = r_n。

**对应关系记忆法**：每一步中——
- 上一行的除数 → 下一行的被除数（b → r₁ 的位置）
- 上一行的余数 → 下一行的除数（r₁ → 做除数）
- 新产生更小的余数 → 再下一行的除数

如此循环往复，余数越来越小，直至为 0。

**课堂练习**：求 (543, 21)。
- 543 = 21×25 + 18
- 21 = 18×1 + 3
- 18 = 3×6 + 0
- 故 (543, 21) = 3

韩老师反复强调：辗转相除法是**"每次考试的第一道题目"**，必须熟练掌握。它不仅本身重要，而且是一元二次不定方程求解（1.5 节）的基础。

**变量 GCD 示例**：(n+1, n) = 1 对所有整数 n 成立。证明：n+1 = n×1 + 1，由核心引理 (n+1,n) = (n,1) = 1。

### 主题六：公因数集合等于最大公因数因子集合

**推论**：设 d = (a, b)，则 a 和 b 的所有公因数构成的集合恰好等于 d 的所有正因数构成的集合。

**证明**（双向包含）：
- **公因数 ⊆ d 的因数**：设 e | a 且 e | b。做辗转相除，从第一步 a = bq₁+r₁，由 e|a 且 e|b 得 e|r₁；逐步向下，最终 e|r_n = d。故 e 是 d 的因数。
- **d 的因数 ⊆ 公因数**：设 f | d，则 d = f·k。由于 d|a 且 d|b，由整除传递性得 f|a 且 f|b，故 f 是公因数。

**意义**：这个推论统一了"公因数"和"最大公因数的因数"两个概念——任何公因数必然是最大公因数的因数，反之亦然。最大公因数名副其实地"包含"了所有公因数。

### 主题七：多个数的最大公因数

**方法**：化多为两——逐对求 GCD。
$$d_2 = (a_1, a_2),\; d_3 = (d_2, a_3),\; \ldots,\; d_k = (d_{k-1}, a_k)$$

最终 d_k = (a_1, a_2, ..., a_k)。

每一步只需求两个数的 GCD（已有辗转相除法），这是典型的"化未知为已知"策略。
