## 关键概念
- **二元运算**：S×S→S 的映射，要求对任意 (x,y)∈S×S 存在唯一的 z∈S 使得 f(x,y)=z
- **封闭性**：运算结果仍在原集合中；从二元运算定义自然满足，重点在于子集是否仍满足封闭
- **运算表**：有限集合上二元运算的表格表示；交换律 ⇔ 表关于对角线对称
- **幂集 P(A)**：集合 A 的所有子集构成的集合
- **函数空间 B^A**：从 A 到 B 的所有映射构成的集合，|B^A| = |B|^|A|
- **对称差**：A⊕B = (A−B)∪(B−A)，满足交换律和结合律，空集为单位元，每个元素自逆

## 要点详述

### 主题一：结合律的工程意义 [00:00-05:36]

以矩阵链乘法为例：A(100×20), B(20×2000), C(2000×10)

**方案一 ((AB)C)**：
- AB：每个元素需 20 次乘法，结果矩阵 100×2000，共 100×2000×20 = 4,000,000 次
- 再乘 C：每个元素需 2000 次，结果 100×10，共 100×10×2000 = 2,000,000 次
- 总计：6,000,000 次乘法

**方案二 (A(BC))**：
- BC：结果 20×10，共 20×10×2000 = 400,000 次
- 再乘 A：结果 100×10，共 100×10×20 = 20,000 次
- 总计：420,000 次乘法

> 结合律允许选择最优运算次序，极大地缩减计算规模。只需考虑乘法次数（加法次数可忽略不计）。

### 主题二：二元运算与三种基本性质 [09:03-34:24]

**二元运算的严格定义**：
- 设 S 为非空集合，映射 f: S×S → S 称为 S 上的一个二元运算
- 关键点：对任意 (x,y)∈S×S，存在**唯一**的 z∈S 使得 f(x,y)=z
- "唯一性"的逻辑表述：∃z(f(x,y)=z) ∧ ∀z'(f(x,y)=z' → z'=z)

**封闭性的再理解**：
- 从二元运算的定义（值域⊆S）封闭性自动满足
- 真正需要封闭性的场景：考虑 S 的**子集** S₁ 时，需验证 f 限制在 S₁ 上是否仍封闭
- 软件工程类比：类库设计理想状态——子系统（子结构）独立封装，调用局部功能时无需加载整个系统

**三种基本运算律**：
- **交换律**：f(x,y) = f(y,x)；从运算表看即关于对角线对称
- **结合律**：f(f(x,y),z) = f(x,f(y,z))；从运算表较难直接判断
- **分配律**：两种运算之间的协调关系

### 主题三：常见代数结构检验 [30:05-34:24]

| 运算 | 交换律 | 结合律 | 单位元 | 逆元 | 消去律 |
|------|--------|--------|--------|------|--------|
| 实数加法 | ✓ | ✓ | 0 | -a | ✓ |
| 实数乘法 | ✓ | ✓ | 1 | 1/a(a≠0) | a≠0时 |
| 集合并 | ✓ | ✓ | ∅ | 无 | — |
| 集合交 | ✓ | ✓ | 全集E | 无 | — |
| 集合差 | ✗ | ✗ | 无 | 无 | ✗ |
| 对称差 | ✓ | ✓ | ∅ | 自逆 | — |
| 函数复合 | ✗ | ✓ | 恒等映射 | 双射才有 | — |

> 函数复合特别关键：当 A 为有限集时，A 上所有双射构成**对称群（置换群）S_n**。

### 主题四：函数空间的基数 [25:19-30:05]

记号 B^A = {f: A→B}，基数公式 |B^A| = |B|^|A|：
- A 中每个元素有 |B| 种像可选
- 共 |A| 个元素，各元素选择独立
- 因此总映射数为 |B| × |B| × ... × |B| = |B|^|A|

> 这也是为什么用 B^A 表示函数空间——既是记号也是基数关系。
