## 关键概念

- **模 $2^\alpha$ 有解条件**：
  - $\alpha=1$：$a\equiv 0,1\pmod{2}$ 均有解（1个解）
  - $\alpha=2$：$a\equiv 0,1\pmod{4}$ 时有解（$a\equiv 1$ 时2个解）
  - $\alpha\ge 3$：$a\equiv 1\pmod{8}$ 时有解（4个解）
- **$2^\alpha$ 下解的个数规律**：$\alpha=1$→1个；$\alpha=2$→2个；$\alpha\ge 3$→4个（不再随 $\alpha$ 增长）
- **一般模 $m$ 二次同余式判定流程**：$m=2^\alpha\prod p_i^{\alpha_i}$ → 分别判断 → 各有解则原方程有解，解数为各模解数之积
- **二次同余式提升**：与第2章 Hensel 提升完全一致，导数条件自动满足（$2x_1$ 与 $p$ 互质当 $p$ 为奇素数）

## 要点详述

### 1. 一般模 $m$ 二次同余式的完整判定

```
x² ≡ a (mod m)
    │ 分解 m = 2^α · ∏ p_i^{α_i}
    ▼
┌──────────────────────────────────┐
│ 模 2^α:                          │
│   α=1: 恒有解（a≡0,1）            │
│   α=2: a≡1(mod 4) 时有2解         │
│   α≥3: a≡1(mod 8) 时有4解         │
├──────────────────────────────────┤
│ 模 p_i^{α_i} (奇素数):             │
│   (a/p_i)=1 → 有2解              │
│   (a/p_i)=-1 → 无解              │
│   p_i|a → 转化为互质情况判断      │
└──────────────────────────────────┘
    │ 所有子问题都有解?
    ▼
 是 → CRT组合，解数 = ∏(各模解数)
 否 → 无解
```

### 2. $x^2\equiv 61\pmod{100}$ 完整计算

- 模4：$61\equiv 1\pmod{4}$ → 有2解：$x\equiv 1,3\pmod{4}$
- 模25：先模5，$61\equiv 1\pmod{5}$，$1^2\equiv 1$ → 模5有2解：$x\equiv \pm 1\equiv 1,4\pmod{5}$
  - 从 $x\equiv 1\pmod{5}$ 提升：得 $x\equiv 6\pmod{25}$
  - 从 $x\equiv 4\pmod{5}$ 提升：得 $x\equiv 19\pmod{25}$
  - 模25共2解：$x\equiv 6,19\pmod{25}$
- CRT组合：4组组合 → 4个模100的解
